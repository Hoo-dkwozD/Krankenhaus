# Private local material

This directory is intentionally ignored by Git except for this README.

Place only local references or encrypted material here, for example:

- `credentials.env` with restrictive permissions (`chmod 600`),
- a Burp project file,
- raw request/response captures,
- approved OOB listener details,
- temporary fixture identifiers.

Do not commit this directory's contents. Do not put passwords, tokens, API keys, private certificates, or raw PII in Markdown, CSV, YAML, evidence, or findings files.
